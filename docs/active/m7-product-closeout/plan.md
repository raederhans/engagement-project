## Acceptance criteria

- Every lane starts from exact `main@dfb4bc8`, uses an isolated worktree, and supplies a commit-level delivery package.
- ML M7 ends in either `no-promotion` or `shadow-admitted`; production forecast stays unavailable and route ranking stays isolated from ML forecasts.
- Public Scenario Mode uses only precomputed public landmark OD pairs and walking; it never accepts or transmits private endpoints.
- Local Private Mode binds only to loopback and mechanically demonstrates zero private route egress; missing engine/evidence remains unavailable.
- Route presentation exposes Pareto/trade-offs and uncertainty, never `Safest`, a safety/risk score, personal victim probability, or a single safety winner.
- Validation distinguishes deterministic fixtures, real engine evidence, manual adjudication, browser/Axe evidence, and remote deployment evidence.
- Combined local validation passes on the exact integrated tip; remote push/deploy/settings remain separately stated until authorized and verified.
